# Косметология — Веб-сайт салона красоты

## О проекте

Этот проект был разработан мной с использованием **HTML** и **Tailwind CSS**. Сайт посвящён косметологии и предназначен для представления услуг косметологического центра в современном и удобном формате.

Основная цель проекта — создать красивый, адаптивный и удобный веб-сайт, который позволяет пользователям ознакомиться с услугами, преимуществами центра и связаться со специалистами.

## Используемые технологии

* HTML5
* Tailwind CSS
* Git & GitHub

## Функциональность

* Адаптивный дизайн для мобильных устройств и компьютеров
* Современный и чистый пользовательский интерфейс
* Информационные блоки об услугах косметологии
* Раздел с преимуществами центра
* Контактная информация
* Удобная навигация по сайту

* HTML-разметкой

## Запуск проекта

1. Склонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

2. Откройте папку проекта.

3. Запустите файл `index.html` в браузере.
